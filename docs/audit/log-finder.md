# Audit: Log Finder

Upstream: `upstream/LogFinder/LogFinder.js` and `index.html`, with `Libraries/LogHelpers.js`,
`Param_Helpers.js`, `OpenIn.js`, the JsDataflashParser, Tabulator 6.2.1, luxon 3.4.4, tippy and
Leaflet 1.9.4. Port: `apps/log-finder/src/`.

Oracle tests (`src/analysis/test-utils/upstream.ts` runs upstream `LogFinder.js` in `node:vm`
with the upstream parser; `src/analysis/test-utils/tabulator.ts` drives upstream Tabulator's own
`Sort` module from `upstream/modules/tabulator`):

- `oracle.test.ts`: every `load_log` field on two real logs, the map tooltip's polyline points,
  `get_param_diff` with each ignore setting, the ignore rules, `param_to_string`, the `.param`
  text.
- `table-oracle.test.ts` (added in this audit): row order after sequences of header clicks on
  every sortable column, per-row diffs from `update_param_diff`, the total diff from
  `total_param_diff_calc`, the diffs after an ignore option changes, and the `size_format`,
  `flight_time_format`, `get_dist_string` and `get_common_path` functions lifted verbatim from
  `setup_table`.

## Remaining intentional differences

- **Conveniences** (no computed result changes): the Vehicle column (`DataflashLog.vehicleType()`,
  which upstream does not compute; not sortable, because sorting decides which rows are diffed),
  the filters (text, dates, vehicle, flown only, with warnings), the Stop button, the
  skipped-files list, choosing files or dropping a folder in addition to the directory picker,
  the per-board "n of m logs" badge, and the OS/board name tooltip on the firmware cell. Filters
  only hide rows: diffs, totals and sort guesses are computed over all of a board's logs, exactly
  as upstream's tables hold them.
- **Removed additions**: the separate Plotly flight-path section, and the rail's total size and
  total flight time across all boards (sums upstream does not compute).
- **Crashes**: when upstream's `load_log` throws after parsing (a corrupt log), the exception
  escapes `FileReader.onload`, the scan's promise never resolves and the page stops with the
  error alert. The port lists the file as skipped and carries on.
- **Popups** are click-opened popovers instead of hover tooltips (presentation).

## Upstream bugs reproduced

| Location                                     | Reproduction                                                           | Effect                                                                                                                                                                              |
| -------------------------------------------- | ---------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `initial_load()` ignore checkbox handler     | Sort a table by Size, then tick or untick an ignore option             | Diffs are recomputed over `table.getRows()`, which is data (scan) order, so each row is compared with the log scanned before it, not the row above, until the table is sorted again |
| Tabulator column sorter guess (`findSorter`) | Click "Flight Time" when the first displayed log has no `STAT_FLTTIME` | The column is compared as strings for the rest of the session (`"300"` before `"60"`)                                                                                               |
| Tabulator `string` sorter on "Name"          | Logs `9.BIN` and `10.BIN` sorted by name                               | `10.BIN` sorts before `9.BIN` (no natural ordering)                                                                                                                                 |
| `size_format`                                | A log of 1024 TB or more                                               | The unit prints as `undefined`                                                                                                                                                      |
| `setup_table` board grouping                 | A board whose boot line is an array index, e.g. `123`                  | That table is listed before boards found earlier in the scan                                                                                                                        |

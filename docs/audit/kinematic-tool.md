# Kinematic Tool audit

Port: `apps/kinematic-tool`. Upstream: `upstream/KinematicTool/` (copter page: `index.html`,
`KinematicTool.js`, `params.json`) and `upstream/KinematicTool/plane/` (plane page), plus
`Libraries/Array_Math.js`, `Libraries/Plotly_helpers.js`, `Libraries/ParameterMetadata.js`,
`ardupilot/control.wasm` and `Ruckig/` that they load.

Oracle: `src/test-utils/upstream.ts` loads each upstream page's JavaScript in `node:vm` (stub DOM
and Plotly, the same `control.wasm` and Ruckig build) and records the plot data, which plots were
redrawn and whether `run_attitude()` threw. `src/analysis/simulate.test.ts` compares 25 copter and
15 plane cases bit for bit, including empty (NaN) inputs and both kinds of Ruckig failure.

Statuses: **identical** (same result, possibly restructured code), **presentation**,
**convenience** (changes no computed result), **browser-forced**, **reverted-in-this-audit**.

## Remaining intentional differences

- **Ruckig failure (copter).** Upstream throws: for an unregistered Ruckig result code (e.g. a
  zero acceleration limit) inside `update_ruckig`, before any plot is redrawn; for a registered one
  (-100/-101/-110, e.g. a negative limit or NaN input) at the jerk plot, after redrawing angle,
  rate and acceleration with a one-point `minimum time` trace. Either way the global handler shows
  "Sorry, something went wrong...". The port shows an error banner naming the Ruckig failure and
  draws the sqrt and S-curve results on all four plots, without the minimum-time trace. Allowed
  by the crash clause; the sqrt and S-curve numbers are identical (oracle checks them whenever
  upstream drew them).
- **`sampleTimes` length.** Upstream's `new Array(len)` throws for a NaN or infinite trajectory
  duration; the port throws the same `RangeError` and reports it as a Ruckig failure (crash clause).
- **Number input step.** Parameters use the metadata `Increment` as the spinner step and the
  desired/initial inputs use `any`; upstream inputs have no `step` (1). Convenience: only the
  arrow-key increment differs; the value used is the value shown.
- **Live recompute** while typing (convenience, above), **wording** of trace names, help and intro,
  **layout** (rail instead of fieldsets), **target line colour**.
- **Load failure** of the wasm modules shows an error banner (upstream would reject silently).

# Upstream bugs

Bugs found in the original WebTools while porting. The port reproduces each one so results match;
each entry says where it is, how to reproduce it, and what a fix would change.

| Tool               | Bug                                                                                             | Where (upstream)                                                                                               | Effect                                                                                                                                                                                                                           |
| ------------------ | ----------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Kinematic Tool     | Ruckig result not registered by embind is dereferenced                                          | `KinematicTool/KinematicTool.js` `update_ruckig` (`result.value`)                                              | Copter with `ATC_ACC_R_MAX` = 0: `result` is `undefined`, the page throws and no plot updates. Port shows an error banner (crash clause).                                                                                        |
| Kinematic Tool     | Jerk plot reads a missing Ruckig jerk array after a Ruckig error                                | `KinematicTool/KinematicTool.js` `run_attitude` (`array_scale(ruckigState.jerk, ...)`)                         | Copter with `ATC_ACC_R_MAX` = -100 or an empty input: angle, rate and acceleration redraw with a one-point minimum-time trace, then the page throws and the jerk plot is not redrawn. Port shows an error banner (crash clause). |
| Kinematic Tool     | Empty inputs are simulated as NaN                                                               | Both pages, `run_attitude` (`parseFloat(...value)`)                                                            | An empty end time always runs to 20 s; an empty desired angle never settles; NaN propagates into the plots and often into a Ruckig failure. Reproduced.                                                                          |
| Kinematic Tool     | Plane page shows the copter Parameters tooltip                                                  | `KinematicTool/plane/index.html`                                                                               | Mentions `ATC_SLEW_YAW` and acro on the plane page.
